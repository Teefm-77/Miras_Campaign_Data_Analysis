# Miras_Campaign_Data_Analysis
# مراجعة تحليل خاطئ وإعادة بنائه - حملة ربيع القهوة

مستودع يحتوي على المراجعة المنهجية والتحليل الإحصائي لإعادة بناء تقرير أداء حملة "ربيع القهوة" التسويقية، بهدف كشف العيوب المنهجية وتصحيح الحسابات رقمياً باستخدام لغة بايثون.

## محتويات المستودع
* Miras_Campaign_Data_Analysis.ipynb: دفتر العمل البرمجي الذي يحتوي على الأكواد والتحليلات الإحصائية كاملة.
* campaign-report.html: مذكرة المراجعة النهائية الموجهة للجنة التنفيذية والتي تقابل كل عيب بأثره العددي والبديل المنهجي.

## العيوب المنهجية التي تم كشفها وتصحيحها

### 1. اقتطاع المدى الزمني
* العيب: اقتطاع المدى الزمني عشوائياً لإظهار نمو وهمي بنسبة 33%.
* الأثر العددي البديل: نسبة النمو الحقيقية الموزونة للمدى الزمني كاملاً طوال الـ 12 شهراً هي 42.55%.

### 2. انحياز الاختيار ومقارنة مجموعات غير متكافئة
* العيب: مقارنة فروع الحملة بالفروع الأخرى دون مراعاة تفاوت الحجم التاريخي الأصلي بينها.
* الأثر العددي البديل: فروع الحملة كانت أضخم بطبيعتها بمقدار 2.26 ضعف بقية الفروع قبل بدء الحملة أصلاً.

### 3. خلط الارتباط بالسببية وإغفال المتغير الثالث
* العيب: نسبة كل النمو للحملة التسويقية وتجاهل تداخلها التام مع التخفيضات السعرية العامة، وهو ما يقع تحت مفارقة سيمبسون.
* الأثر العددي البديل: الفترات المشتركة حققت 4,853,293.36 ريال، بينما حقق خفض السعر بمفرده دون حملة 2,981,923.90 ريال، مما يثبت أن التخفيض السعري هو المحرك الأساسي.

### 4. الحساب الخاطئ لمتوسط قيمة الطلب
* العيب: حساب متوسط المتوسطات بشكل مباشر دون وزنه بحجم الطلبات الفعلي لكل فرع.
* الأثر العددي البديل: المتوسط المرجح الصحيح خلال الحملة هو 110.26 ريال وخارجها 107.92 ريال.

## الخلاصة الإحصائية
بناءً على الفحص المنهجي، لا يمكن إثبات وجود أي علاقة سببية مباشرة بين الحملة التسويقية وزيادة المبيعات نظراً لغياب العشوائية وتداخل المتغيرات الكامنة التي لم يتم عزلها برمجياً وإحصائياً.
